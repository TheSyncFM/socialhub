# SocialHub V1 — TheSyncFM

Prototype gratuito del pannello SocialHub.

## Cosa contiene
- Dashboard
- Stato live
- KPI social
- Calendario live
- Link-in-bio
- Social collegati
- Attività recente
- Responsive desktop/mobile

## Come provarlo
Apri `index.html` con un browser.
